# Downloader Codes for Android TV & Fire TV

Downloader codes for Android TV and Firestick apps (official sources only).
Full directory with more apps, details and updates: **[downloadercodes.com](https://downloadercodes.com)**

## Disclaimer
This repository does not host APK files.
All entries must point to official sources only (app stores or official developer sites).

## How to use
1. Install **Downloader** (official)
   - Google Play: https://play.google.com/store/apps/details?id=com.esaba.downloader
   - Amazon App Store: https://www.amazon.com/dp/B01N0BP507/
2. Open the Downloader app on your Android TV / Firestick.
3. Select the URL field and enter a code from this list.
4. The code resolves to a direct APK download from the app's official developer website (or the developer's official download domain).
5. After the download finishes click install.

More details: [How to use Downloader codes](https://downloadercodes.com/blog/how-to-use-downloader-codes/)
Not sure a code still works? Try the [Downloader Code Checker](https://downloadercodes.com/downloader-code-checker/).
