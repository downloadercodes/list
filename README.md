## How to use

### Install Downloader (official)
- Google Play: https://play.google.com/store/apps/details?id=com.esaba.downloader
- Amazon App Store: https://www.amazon.com/dp/B01N0BP507/


### Use a code (direct APK links)
1. Open the **Downloader** app on your Android TV / Firestick.
2. Select the **URL** field and enter a code from this list.
3. The code resolves to a **direct APK download** from the app’s **official developer website** (or the developer’s official download domain).
4. After the download finishes click **install**.
- More deailes: https://downloadercodes.com/blog/how-to-use-downloader-codes/
